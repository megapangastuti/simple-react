1. first class citizen => sesuatu tersebut bisa menjadi sebuah variabel
2. kalo di bahasa lain, function g bisa jadi variable
3. typescript => function bisa masuk ke variable
4. first class func => sebuah func yang dapat dideklarasikan sebagai variable serta dapat dikirim ke suatu func sebagai argumen
5. argumen => sesuatu yang akan diproses sama function
6. parameter => isi dari function
7. pure function itu selalu ada return nya
8. first class function bisa jadi element dalam array
9. apa itu function?
   - mengisolasi proses pada lingkup tertentu
   - dapat memiliki nilai balikan (return value) atau tidak ada nilai balikan(void)
   - block-code yang dibuat untuk mengerjakan tugas tertentu
   - function
10. functional programming adalah ...
    - pendekatan atau cara melakukan pemrograman dengan pola pikir(paradigma)
11. konsep pertama functional programming :
    - imperative
    - declarative
12. imperative :
    - menyatakan urutan detail dari suatu peristiwa atau pelaku yang terjadi
    - menjelaskan "bagaimana" seharusnya terjadi
13. declarative :
    - menyatakan peristiwa atau perilaku apa saja yang harusnya terjadi
    - menjelaskan "apa" yang harus terjadi
14. immutability
    - mutable => bisa diubah
    - immutable => tidak bisa diubah
    - immutability => kemampuan untuk tidak mengubah apapun
    - nilai dari suatu variable yang diproses di dalam function tidak boleh berubah dari nilai awalnya
15. pure function :
    - setidaknya mempunyai 1 argumen dan selalu mengembalikan nilai atau function
    - pure function sangat memungkinkan untuk di uji (testable)
